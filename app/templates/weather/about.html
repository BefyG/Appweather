🌟 What is this app?

This is a simple and beautiful weather checking application built with Django. Enter any city name and get instant weather information including temperature, conditions, and more!

🔧 How it works

The app uses the OpenWeatherMap API to fetch real-time weather data. All your weather searches are stored in a database for you to review in the history section.

📊 Features

  • 🌍 Real-time weather data for any city
  • 📚 Weather search history
  • 🎨 Beautiful, animated interface
  • 📱 Responsive design
  • 🔒 Secure data storage

🛠️ Technologies Used

Built with Python, Django, HTML, CSS, and JavaScript. Powered by OpenWeatherMap API.
